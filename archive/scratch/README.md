# Scratch experiment archive

This directory retains 75 unique one-off experiment and diagnostic scripts from the pre-Git research period. It is not a supported execution surface.

The retained files cover:

- dated DiT training, continuation, and evaluation commands;
- action/chunk/checkpoint diagnostic probes;
- rescue sweeps and conditioning checks;
- early direct-skill and skill-token trials.

Exact duplicate root/script copies and machine-specific PowerShell fetch, remote-inspection, and synchronization helpers were removed. One differing root copy of the offline-action-error probe is retained with `.root_variant` in its name.

Use Git history when reconstructing an old machine workflow. Do not launch a new mainline experiment from this directory without reviewing and migrating the configuration into a maintained entry point.
